### 🚀 Featured Projects

**[CropSense](https://github.com/riteshyadav-345)** — Crop disease detection system: a CNN built with MobileNetV2 transfer learning trained on the 54K-image PlantVillage dataset across 15 disease classes (93% accuracy), wrapped in a Flask web app with a treatment-recommendation database.

**AI Candidate Ranking System** — Built for the Redrob AI "Data & AI Challenge" hackathon: a candidate-ranking pipeline for 100K+ candidates using sentence-transformers + BM25 hybrid scoring, multi-component rule-based ranking, and hard-gate honeypot detectors. Shipped as a CLI pipeline, a 9-slide deck, and a submission CSV — 31/31 unit tests passing.

**AWS Data Lake & Analytics Platform** — Multi-country e-commerce analytics on AWS: a multi-zone data lake with Glue/Athena, Parquet storage with 4-level partitioning, and QuickSight dashboards, with a focus on Athena query optimization.

**[Placement Prediction](https://github.com/riteshyadav-345/Placement_Prediction_ML-Project1)** — ML project predicting student placement outcomes.

**Splice** — A client-side video-merging tool built entirely in the browser using HTML5 Canvas, MediaRecorder, and the Web Audio API — no backend required.
